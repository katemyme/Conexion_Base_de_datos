## ⚠️ Instrucciones para Estudiantes

Si vas a clonar o descargar este repositorio, por favor sigue estas reglas:

1. **Elimina o reinicia el `.git`:** Borra la carpeta oculta `.git` al copiar los archivos para no generar errores ni conflictos con el historial de este repositorio original.
2. **Actualiza las credenciales:** Recuerda cambiar los usuarios, contraseñas y cadenas de conexión por los tuyos antes de ejecutar el proyecto.
3. **No alterar este origen:** Por favor, **no hagas commits ni pushes** hacia este repositorio.
